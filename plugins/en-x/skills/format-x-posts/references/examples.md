# Reply Examples

These examples show the quality bar for replies. Each anchors to a specific part of the source and contributes a claim; none merely restates the source.

## AI agents and parallelism

Source idea: parallel agents increase software-development throughput.

> Parallel agents can give you several 80% solutions faster. The integration and review cost still lands on the human, so throughput rises without the same increase in confidence.

Why it works: "several 80% solutions" anchors the reply to parallel output, while the human integration and review cost adds a concrete mechanism and consequence. It does not repeat the broad throughput claim.

## Confidential tokens

Source idea: confidential tokens can support onchain financial applications.

> Who controls disclosure here: the issuer, auditor, or holder? That choice determines whether a wallet or AMM can integrate without inheriting a privileged data path.

Why it works: the reply identifies a specific design decision, names the actors who could control it, and connects the answer to wallet and AMM integration. The question asks for information that materially changes the implementation.

## Agent interfaces

Source idea: running more agents in parallel makes agents more useful.

> Inspecting the prompt and execution state is what makes an agent steerable. Parallelism helps less when you cannot see which assumptions each run is carrying.

Why it works: the reply makes visibility into prompts, execution state, and assumptions the mechanism for steering. It adds a constraint on the usefulness of parallelism instead of paraphrasing the source.
