# Daml Development

Develops, reviews, debugs, and tests Daml smart contracts for Canton Network, with particular attention to authorization, privacy, contract lifecycle, multi-party workflows, and version-aware tooling.

## Included references

- `language.md` covers the Daml language, templates, choices, interfaces, contract keys, standard-library helpers, and Daml Script.
- `patterns.md` covers reusable multi-party, authorization, settlement, and state-management patterns.
- `canton35.md` covers the Canton 3.5 and SDK 3.5 toolchain and migration snapshot.

These files are supporting references, so they intentionally do not contain skill frontmatter. The discoverable skill metadata and routing live in [`SKILL.md`](SKILL.md).

## Use

```text
# Codex
$en-canton:daml-development Review this Daml template for authorization and privacy issues.

# Claude Code
/en-canton:daml-development Design and test a propose-accept workflow.
```
